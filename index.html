api endpoints

get and post · public · no user key required
base url
get /api

returns api information and available endpoints.

get /api/games

returns all games from available catalogs.

get /api/games?source=seraph

returns games from seraph only.

get /api/games?source=truffled

returns games from truffled only.

get /api/games?search=mario

searches game names and ids.

get /api/games?limit=300

limits results. maximum supported limit: 1000.

get /api/cover?name=mario

finds a remote cover and redirects to its image url.

post /api/summary

generates a groq ai catalog summary.

get /api/health

checks api availability and ai configuration.

quick integration

retrieve the complete game catalog from your html.

const response = await fetch(
  "https://gmshelf-api.workers.dev/api/games?limit=1000"
);

const data = await response.json();

data.games.forEach(game => {
  console.log(game.name);
  console.log(game.cover);
  console.log(game.url);
});
