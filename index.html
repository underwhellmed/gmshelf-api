base url

endpoints

GET/api/health

check that the api is online. returns { ok: true, version }.

GET/api/games?limit=1000

list games. each game has name, url, cover and source. use limit to cap the amount.

GET/api/cover?name=minecraft

a fallback cover image generated for a game name.

POST/api/summary

generate a short summary of a game. send json with name, url and source.
